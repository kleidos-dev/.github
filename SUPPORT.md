# Getting help

- **Questions** about how Kleidos works, or why it does not: [Q&A](https://github.com/orgs/kleidos-dev/discussions/categories/q-a) in Discussions.
- **A board you would like it on**: [New board requests](https://github.com/orgs/kleidos-dev/discussions/categories/new-board-requests).
- **A vulnerability**: never in public. Follow [SECURITY.md](SECURITY.md).

There is no support by email. Kleidos has one maintainer, and answers come when there is time for them.
